# Project — SalesFlow Widget

Embedded support widget for **SalesFlow** — a cloud document collaboration
platform (think Google Docs + smart templates for contracts, RFPs, SOWs). The
widget serves pre-sales prospects and free-tier customers in the product:
answers product questions, deflects common setup issues, and escalates to
human sales/support when needed.

## Product context
- **Surface**: embedded widget — floating panel (bottom-right) or right sidebar.
- **Audience**: SMB prospects (5–100 seats) evaluating SalesFlow + free-tier and trial users.
- **Goal**: cut friction on self-serve; instant answers to FAQs; escalate complex issues + demo requests.
- **Escalation map**: legal → Sales Desk; technical setup beyond docs → Support; feature requests → Product.

## Knowledge base topics
- **Getting started**: workspace creation, invites, importing documents, template use.
- **Pricing**: free vs Pro vs Enterprise, seat pricing, per-template overage.
- **API / integration**: Zapier, REST API, webhooks, OAuth.
- **Template library**: built-in templates, custom templates, version control.
- **Common issues**: SSO problems, slow uploads, permission errors.

## Escalation triggers
- User asks "transfer me to sales" or mentions contract law → Sales Desk.
- User reports a bug or missing feature not in docs → Support.
- User has 10+ failed API calls in one conversation → Support.
- Conversation exceeds 8 exchanges without resolution → human handoff.

## Voice
- Friendly, direct, no filler. Peer-to-peer, not FAQ-bot.
- Lead with the answer, then offer resources.
- 2–3 sentences max per turn; link out for depth.
